# Perfect-Day--A-Michael-Jackson-FanWebsite
An interactive Michael Jackson fan experience celebrating his legendary journey, iconic albums, historic 1984 Grammy night, background music, and a trivia quiz.


**Perfect Day** is an interactive fan website dedicated to Michael Jackson and one of the most iconic moments of his career — the night he made history at the **1984 Grammy Awards**.

The website takes visitors through Michael Jackson's legendary journey, featuring his iconic albums, memorable achievements, interactive navigation, background music, and a quiz designed to test how well you know the King of Pop.

# Features

- Interactive splash screen
- Background music with Music ON/OFF control
- Interactive homepage navigation
- A journey through one of Michael Jackson's most historic nights
- Interactive album gallery featuring his solo studio albums
- Album-by-album navigation experience
- Interactive Michael Jackson quiz with 10 questions
- Instant correct and incorrect answer feedback
- Dynamic quiz score and fan-level results
- Play Again functionality
- Quick navigation back to the homepage
- Responsive design for different screen sizes

# How It Works

The website uses an image-based interactive interface combined with custom JavaScript hotspots.

Visitors can navigate through different sections of the website by clicking on specific areas of the visual design. JavaScript dynamically manages:

- Screen navigation
- Album pages
- Interactive hotspots
- Quiz questions and answers
- Score calculation
- Dynamic quiz results
- Background music controls
